# Grupo Bimbo (BIMBOA) wiki

Compiled knowledge base for the CFA Research Challenge, built with the Knowledge-Management-System layout (`filings/` -> `wiki/`). Articles are in English; every number carries a data tag and a page/sheet citation.

- `wiki/` — 47 articles by domain (this folder). Operating manual: [WIKI.md](WIKI.md); slash commands and skill: [kit/claude](kit/claude).
- `data/capitaliq/` — 31 tidy CSVs extracted from the S&P Capital IQ Excel exports.
- `filings/` — source PDFs (annual reports, BMV filings, earnings releases, financing framework) and the original Capital IQ Excel exports (`filings/capitaliq/`).
- `ciq-*` articles are derived from Capital IQ exports (S&P Global data; use under your own license).

To replicate: copy these folders into a project, add `.claude` from `kit/claude`, and run `/compile` for new sources.
